# 电商用户行为数据分析项目

> 基于用户全链路行为日志，定位转化卡点、识别用户价值、输出可落地的运营优化方向

---

## 一、项目概述

### 1.1 项目背景

本项目基于一家化妆品电商平台的真实用户行为日志，围绕用户从**浏览 → 加购 → 购买**的完整决策链路展开分析。通过漏斗分析、同期群留存、RFM 用户分层与商品关联规则挖掘等方法，定位转化流失的关键环节，评估用户留存与复购表现，并输出可落地的运营优化方向。

### 1.2 分析目标

- **看清流量**：掌握平台整体流量规模，识别流量在日期与时段上的分布规律；
- **定位卡点**：拆解全链路各环节转化效率，定位核心流失环节与品类转化差异；
- **识别价值**：评估用户月度留存与复购表现，对购买用户进行价值分层；
- **挖掘连带**：发现商品之间的连带购买关系，为交叉销售与组合运营提供依据；
- **输出动作**：将分析结论转化为可执行、可验证的运营优化方向。

### 1.3 数据来源

- **数据集名称**：[eCommerce Events History in Cosmetics Shop](https://www.kaggle.com/datasets/mkechinov/ecommerce-events-history-in-cosmetics-shop)
- **数据作者**：Michael Kechinov（数据由 [Open CDP](https://github.com/open-cdp) 项目收集）
- **数据说明**：数据集记录了某中型化妆品在线商店 2019 年 10 月至 2020 年 2 月（共 5 个月）的用户行为，每行代表一次用户事件（浏览、加购、移除购物车、购买）。**本项目使用全部 5 个月数据**开展分析。
- **许可证**：Data files © Original Authors。本项目仅用于学习与研究。
- **注意**: 原始数据不入库，需自行从 Kaggle 下载

> 在此向数据集原作者及 Kaggle 平台致谢。

### 1.4 核心分析结论摘要

| 维度 | 关键结果 |
|---|---|
| 数据规模 | 清洗后 16,519,793 条行为记录，1,637,113 名用户，53,675 件商品，523 个品类 |
| 流量特征 | 人均浏览量约 3.95 页；PV 峰值在 19 时，UV 峰值在 12 时，两者不同步 |
| 转化链路 | 浏览用户 1,596,371 → 加购用户 398,124（24.94%）→ 购买用户 109,605（整体 6.87%） |
| 流失环节 | 浏览→加购流失约 75%，是绝对流失量最大的环节；加购→购买再流失约 72.5% |
| 品类差异 | 零转化品类 55 个（占有浏览品类的 10.52%）；部分品类转化率异常偏高，需核查口径 |
| 留存表现 | 次月留存仅 9%—14%，但第 3、4 月降幅明显收窄，流失集中在首月窗口期 |
| 关联规则 | 提升度 39—85，成套购买特征明确；但支持度不足 0.5%，属"强关联、小众"组合 |

## 五、核心指标口径

| 指标 | 计算规则 |
|---|---|
| **PV（页面浏览量）** | 统计周期内 `event_type = 'view'` 的记录总数，同一用户多次浏览分别计数 |
| **UV（独立访客数）** | 统计周期内发生浏览行为的去重用户数（按 user_id 去重） |
| **人均浏览量** | PV ÷ UV，反映用户平均浏览深度 |
| **加购率** | 有加购行为的去重用户数 ÷ 浏览去重用户数 |
| **环节转化率** | 漏斗下一环节去重用户数 ÷ 上一环节去重用户数 |
| **整体转化率** | 购买环节去重用户数 ÷ 浏览环节去重用户数 |
| **分品类转化率** | 该品类发生购买的去重用户数 ÷ 该品类发生浏览的去重用户数 |
| **订单** | 原始数据无订单号，以「同一 user_id + 同一 date」近似定义 |
| **同期群留存率** | 以用户首次活跃月份为同期群，第 N 月仍活跃的用户数 ÷ 该群首月用户数 |
| **R（Recency）** | 用户最近一次购买距数据截止日的天数，越小越优 |
| **F（Frequency）** | 用户购买次数，越大越优 |
| **M（Monetary）** | 用户累计消费金额，越大越优 |
| **支持度 Support** | 某商品组合在全部订单中出现的比例 |
| **置信度 Confidence** | 购买前项 A 的用户中同时购买后项 B 的比例，即 P(B\|A) |
| **提升度 Lift** | 置信度 ÷ 后项出现概率；lift > 1 表示关联有效 |

## 七、已知问题与后续改进

### 7.1 已识别的方法问题

1. **漏斗代码变量复用**：`转化漏斗分析.ipynb` 中 `buy_cnt` 先被赋值为购买独立用户数，随后被覆盖为「购买 ∩ 加购」的用户数，但后续转化率计算仍使用该变量，导致整体转化率的分子口径与变量名不符。
2. **转化率存在两套口径**：基础指标中的加购率（22.42%）与漏斗中的浏览→加购率（24.94%）分子分母定义不同，引用时需注明口径。
3. **品类转化率存在异常高值**：部分品类转化率超过 60% 甚至 90%，不符合常规电商场景，需单独核查是否为口径问题。
4. **RFM 分层维度缺失**：M 维度已计算但未参与分层，F 采用次数分箱导致区分度不足，分层结果高度集中。
5. **关联规则候选集受限**：仅保留销量前 200 的商品，规则覆盖面受限。

### 7.2 可拓展的分析方向

- **分品类漏斗分析**：对高流量品类与零转化品类分别绘制漏斗，定位品类内部流失环节；
- **购买用户留存专析**：对比购买用户与全体用户的留存差异；
- **分时段转化分析**：叠加各时段的加购率与购买率，判断高峰时段是否也是高效转化时段；
- **关联规则与品类交叉**：判断强连带关系集中于品类内还是跨品类；
- **复购用户特征提取**：从复购用户中提取共同特征，为提升复购提供线索。
