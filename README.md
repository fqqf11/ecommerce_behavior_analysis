# 电商用户行为数据分析项目

> 基于用户全链路行为日志，定位转化卡点、识别用户价值、输出可落地的运营优化方案
> 分析周期：2019 年 11 月（共 30 天）

---

## 一、项目概述

### 1.1 项目背景

在电商流量红利见顶、获客成本持续上升的背景下，经营重心已从"获取更多流量"转向"让现有流量产生更高价值"。本项目基于国内某电商平台的用户行为日志数据，围绕用户从**浏览、加购到购买**的完整决策链路，运用漏斗分析、同期群留存、RFM 分层、关联规则挖掘等方法，还原用户真实决策路径，定位业务转化流失的关键环节，挖掘用户价值分层特征，最终输出可落地的运营优化方案。

### 1.2 分析目标

- **看清流量**：掌握平台整体流量规模，识别流量在日期与时段上的分布规律；
- **定位卡点**：拆解全链路各环节转化效率，定位核心流失环节与品类间的转化差异；
- **识别价值**：评估用户留存与复购表现，对用户进行价值分层，识别高价值与流失风险人群；
- **挖掘连带**：发现商品间的连带购买关系，为交叉销售与组合运营提供依据；
- **输出动作**：将分析结论转化为可执行、可落地的运营优化建议。

### 1.3 核心价值

- **业务价值**：以数据驱动的方式定位"高流量、低转化"等资源错配问题，为流量分配、用户召回、品类运营、组合销售提供直接决策依据；
- **技术价值**：构建了 **MySQL 与 Python 双工具交叉验证**的完整分析流程，保证指标口径统一、结果严谨可信；
- **工程价值**：形成从原始数据到静态图表、分析报告、Power BI 交互式看板的**完整可复现分析链路**，可作为数据分析项目的标准化范例。

### 1.4 数据来源

本项目使用的数据集来自 **Kaggle**，为公开的真实电商行为日志：

- **数据集名称**：[eCommerce Events History in Cosmetics Shop](https://www.kaggle.com/datasets/mkechinov/ecommerce-events-history-in-cosmetics-shop)
- **数据作者**：Michael Kechinov（数据由 [Open CDP](https://github.com/open-cdp) 项目收集）
- **数据说明**：该数据集记录了某中型化妆品在线商店 2019 年 10 月—2020 年 2 月（共 5 个月）的用户行为，每行代表一次用户事件（浏览、加购、移除购物车、购买）。**本项目选取其中 2019 年 11 月（共 30 天）的数据**开展分析。
- **许可证（License）**：Data files © Original Authors（数据版权归原作者所有），本项目仅用于学习与研究。

> 在此向数据集的原作者及 Kaggle 平台致谢。

## 四、核心分析内容

### 4.1 流量规模与时间特征分析

- **分析思路**：以浏览行为为基础，按日、按小时统计 PV、UV 及人均浏览量，识别流量的时间分布规律。
- **核心结论方向**：
  - 流量呈"**双高峰、深夜谷**"特征——上午 9—12 时与晚间 17—20 时为两个购物高峰，**19 时为全天峰值**，凌晨 0—5 时为低谷；
  - 月内流量震荡上行，**下旬明显高于上旬**，月末大促节点（28 日）达到全月峰值；
  - 人均浏览深度不足 2.5 页，整体浏览偏浅，"逛购"潜力未被充分激发。

### 4.2 用户转化漏斗分析

- **分析思路**：按"浏览 → 加购 → 购买"构建用户转化漏斗，逐环节计算转化率，并拆解到品类维度。
- **核心结论方向**：
  - 全链路**整体转化率约 12.5%**，"**浏览 → 加购"（约 31.6%）是最大流失卡点**，近七成用户浏览后未加购；
  - "加购 → 购买"转化率约 39.5%，加购是强购买意向信号，加购未购用户是高价值召回人群；
  - 品类转化率分化悬殊，头部品类接近 50%，而**流量最大的品类转化率仅约 10%**，存在明显流量错配。

### 4.3 品类与商品销售分析

- **分析思路**：按品类、商品维度统计订单数、购买人数与销量占比，评估销售集中度，并与浏览量交叉对比。
- **核心结论方向**：
  - 销售高度集中，**TOP3 品类合计贡献约 90% 销量**，呈"头部集中、长尾分散"格局；
  - 商品以"单人单买"为主，复购贡献弱，依赖爆款拉新客的单次成交模式；
  - 存在"**高浏览、低成交**"商品，曝光资源被占用却未有效转化，需诊断或重新分配流量。

### 4.4 同期群用户留存分析

- **分析思路**：以用户首次访问日期划分同期群，计算各群在第 N 日的留存率，形成留存矩阵与热力图。
- **核心结论方向**：
  - 留存呈"**断崖式**"衰减，**次日留存仅约 5.9%**，3 日约 2.6%、7 日约 1.6%，30 日趋近于 0；
  - 各批次留存普遍低迷，留存问题是系统性的，单纯依赖促销无法建立用户忠诚度。

### 4.5 RFM 用户价值分群

- **分析思路**：基于最近购买时间（R）、购买频次（F）、消费金额（M）对成交用户进行价值分层。
- **核心结论方向**：
  - "**重要挽留用户**"（约 52.9%）与"**重要发展用户**"（约 46.7%）合计贡献约 **98.7% 的消费**，是平台绝对主力；
  - 高价值忠诚用户（重要价值、重要保持）**不足 0.4%**，核心忠诚用户层基本缺位，需重点培育。

### 4.6 商品关联规则挖掘

- **分析思路**：以订单为事务，使用 Apriori 算法计算商品组合的支持度、置信度与提升度，挖掘连带购买关系。
- **核心结论方向**：
  - 发现多组强连带商品组合，**提升度高达 45—75**，远高于随机购买水平，具备明确的成套购买特征；
  - 组合支持度较低（0.2%—0.3%），交叉销售目前以用户自发为主，可通过套装运营与推荐位规模化放大。

## 七、核心指标口径

| 指标 | 计算规则 |
|---|---|
| **PV（页面浏览量）** | 统计周期内 `event_type = 'view'` 的行为记录总数，同一用户多次浏览分别计数 |
| **UV（独立访客数）** | 统计周期内发生浏览行为的去重用户数（按 user_id 去重） |
| **人均浏览量** | PV ÷ UV，反映用户平均浏览深度 |
| **加购率** | 发生加购行为（`event_type = 'cart'`）的去重用户数 ÷ 浏览去重用户数 |
| **环节转化率** | 漏斗下一环节去重用户数 ÷ 上一环节去重用户数（如浏览→加购、加购→购买） |
| **整体转化率** | 购买环节去重用户数 ÷ 浏览环节去重用户数 |
| **分品类转化率** | 该品类发生购买的去重用户数 ÷ 该品类发生浏览的去重用户数 |
| **订单数 / 销量** | 统计周期内 `event_type = 'purchase'` 的记录数（按对应维度聚合） |
| **同期群留存率** | 以用户首次访问日期为同期群，第 N 日仍活跃的用户数 ÷ 该群首日用户数；次日留存即 N=1 |
| **R（Recency）** | 用户最近一次购买日期距统计截止日的天数，越小越优 |
| **F（Frequency）** | 用户在统计周期内的购买次数，越大越优 |
| **M（Monetary）** | 用户在统计周期内的消费总金额，越大越优 |
| **RFM 分群** | 以 R、F、M 相对总体均值的高低组合，划分重要价值、重要保持、重要发展、重要挽留等类型 |
| **支持度 Support** | 某商品组合在全部订单中出现的比例 |
| **置信度 Confidence** | 购买前项 A 的用户中同时购买后项 B 的比例，即 P(B\|A) |
| **提升度 Lift** | 置信度 ÷ 后项出现概率，即 P(B\|A) ÷ P(B)；lift > 1 表示关联有效，越大连带越强 |

## 八、总结与优化方向

### 8.1 项目总结

本项目完整覆盖了电商用户从浏览到购买的全链路行为分析，构建了"**数据清洗 → 指标计算 → 多维分析 → 交叉验证 → 可视化与报告 → 交互看板**"的完整分析闭环。通过 MySQL 与 Python 双工具交叉验证保障了结论的严谨性，最终定位了"浏览→加购"转化卡点、"高流量低转化"流量错配、用户留存断崖式下跌、高价值用户稀缺等核心问题，并给出了资源时段配置、购物车召回、按转化效率分配流量、用户分层运营、强关联组合套装等可落地的运营动作，兼具分析深度与业务价值。

### 8.2 可拓展的分析方向

- **数据周期拓展**：引入更长周期（如跨季度、跨年度）数据，分析大促长期效应与用户年度生命周期；
- **渠道与来源分析**：补充流量来源、渠道、投放成本数据，开展渠道 ROI 与归因分析；
- **用户画像拓展**：结合用户地域、设备、人口属性等信息，构建更立体的用户画像；
- **精细化推荐**：将关联规则与 RFM 分层结果应用于个性化推荐与精准营销；
- **预测性建模**：构建用户流失预测、购买意向预测、LTV（用户生命周期价值）预测模型；
- **A/B 测试**：针对运营策略（推送、优惠券、详情页）开展 A/B 实验，实现策略效果的量化验证；
- **实时化看板**：对接实时数据流，构建实时监控与预警看板。
